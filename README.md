Cosmic Companion

Cosmic Companion is a client-side utility mod designed specifically for Cosmic Prisons, providing useful tracking tools and audio notifications to help you keep track of important events while playing.

Features
🔎 Relic Tracking — Tracks relics as they are detected, helping you keep an accurate tally while mining.
🍀 Lucky Block Tracking — Tracks Lucky Blocks in the same way as relics, allowing you to keep track of how many you have found.
🔊 Audio Notifications — Plays an audio notification when a relic or Lucky Block is detected, making it easier to notice them while focused on mining.
⛏️ Mining Utilities — Provides useful tools and tracking features designed around the Cosmic Prisons mining experience.
📊 Gameplay Tracking — Keeps track of useful gameplay information to help monitor your progress.
Compatibility
Minecraft: 1.21.11
Mod Loader: Fabric
Environment: Client-side
Java: 21+
Installation
Install Fabric Loader for Minecraft 1.21.11.
Install the required version of Fabric API.
Download the latest Cosmic Companion .jar.
Place the .jar file into your Minecraft mods folder.
Launch Minecraft using Fabric.
